# Repository review — 20 September 2026

## Scope

Reviewed the repository inventory, restore/install paths, package manifests,
shell initialization, compositor configuration, theme templates, public images,
runtime state and documentation. Compared all 31 iNiR overlays with their pinned
upstream sources, focusing semantic review on the local changes. Configuration,
QML and shader parsers cover the checked-in sources; this is not a line-by-line
correctness proof of all upstream code or an exhaustive security audit.

The reference desktop uses Niri 26.04 and Quickshell 0.3.1. The tested iNiR base
is 2.30.0 at `dcba34ee124acb5a191c88b2e1952006fa5afb2f`, plus local overlays.

## Changes made

| Finding | Resolution |
| --- | --- |
| Browser flags used the old `ozone-platform-hint` option | Use the explicit `--ozone-platform=wayland` switch in Chrome and Code flags |
| Chrome flags attempted to restore removed Manifest V2 support | Removed the obsolete `ExtensionManifestV2Unsupported` override |
| Niri exported an obsolete Electron hint | Removed `ELECTRON_OZONE_PLATFORM_HINT`; modern Electron uses the Wayland session by default |
| The bootstrap wrote raw paths into TOML | Encode the source path as a quoted string; added a regression for quotes, spaces and backslashes |
| Installer version/migration records remained as ignored source snapshots | Removed the stale tracked snapshots while keeping deployment exclusions |
| Documentation claimed a universally minimal install | Documented the actual Arch-only restore scope and machine-level package choices |
| Repository-level MIT wording covered upstream source indiscriminately | Added scoped attribution and upstream GPL text; retained shader notices |
| Public showcase images included personal desktop context | Replaced them with two bounded settings captures and two original SVG illustrations |
| Validation lived partly outside the repository | Added `scripts/validate.py` and an optional Arch-container CI template |

Browser flags require an application restart. The Niri environment change takes
effect for new sessions; current applications were not closed to force it.

## What stayed unchanged, and why

- **iNiR pin:** upstream main was checked at `9574fa42` (2.31.0). It includes iRiS,
  new Settings architecture and substantial bar/service changes. Updating full-file
  overlays without porting them would risk replacing new upstream behavior with old
  implementations. The existing baseline remains until that migration is tested.
- **Package selection:** every name in the official manifest exists in the
  configured repository databases. The broad system list is now described honestly;
  packages were not removed merely because they are optional on this machine.
- **Xwayland and portal setup:** current Niri handles satellite startup on demand;
  existing portal preferences already select GNOME/GTK implementations. No extra
  daemon or alternative shell stack was introduced.
- **Visual preferences and integrations:** retained the existing theme, apps and
  working overlays. Alternative tools were not substituted without a concrete fix
  or compatibility benefit.

## Validation evidence

- 14 offline behavior regressions passed, including the new bootstrap path case.
- 29 QML files and 10 GLSL shader files parsed successfully.
- Bash/Fish, JSON, TOML, font XML and new SVG files passed syntax checks.
- An isolated chezmoi apply/verify passed with scripts and external fonts excluded;
  rendered Niri configuration, private permissions and the Kitty theme link passed.
- The live browser/Niri updates validated; the shell stayed active. iNiR JSON
  preferences remain semantically equal to the source, with formatting-only drift.
- New documentation paths are excluded from deployment; local Markdown links resolve.
- The two new raster captures and both rendered vector illustrations were visually
  inspected. Raw full-desktop preview captures are not included in the repository.
- A targeted text check found no private-key blocks or common GitHub, Google API
  and OpenAI token patterns in the current source. Nonempty credential-like iNiR
  preferences were reviewed; its public example hotspot password is documented.
  This check cannot prove the absence of all possible secrets or sanitize history.

The [earlier live QA](desktop-verification-2026-09-19.md) covered 77 desktop views.
This pass did not repeat that whole sweep or perform a fresh OS install. Battery,
Bluetooth hardware, native Alt+Tab interaction and account-backed integrations
retain the earlier limitations. A passing parser or screenshot is not a guarantee
that every feature works in every environment.
